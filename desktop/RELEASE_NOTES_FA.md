# یادداشت انتشار WhiteDNS Desktop 1.0.0-beta6

WhiteDNS Desktop نسخه دسکتاپ WhiteDNS است؛ یک برنامه ساده برای راه‌اندازی اتصال MasterDNS/StormDNS از روی کامپیوتر، بدون نیاز به کار مستقیم با فایل‌های پیچیده و دستورهای ترمینال.

این نسخه برای کاربران عادی طراحی شده است: کافی است پروفایل اتصال، لیست Resolverها و تنظیمات دلخواه را وارد کنید و از داخل برنامه اتصال را روشن یا خاموش کنید.

## نکات مهم این نسخه

- رابط کاربری دسکتاپ برای مدیریت کامل اتصال WhiteDNS
- اتصال و قطع اتصال با یک دکمه
- پراکسی محلی آماده برای استفاده در مرورگرها و برنامه‌های دیگر
- مدیریت پروفایل‌های مختلف برای اتصال، Resolver و تنظیمات
- بررسی سلامت Resolverها و نمایش وضعیت آن‌ها
- ابزار اسکن برای تست کردن سرورها و Endpointهای واردشده توسط کاربر
- نمایش سرعت، مصرف داده و وضعیت اتصال به‌صورت زنده
- خروجی گرفتن از تنظیمات به شکل فایل `client_config.toml`
- لاگ و بخش عیب‌یابی برای فهمیدن دلیل خطاها
- بسته‌بندی آماده با هسته MasterDNS/StormDNS و Xray-core، بدون نیاز به فایل‌های جداگانه در نسخه نهایی

## امکانات برای کاربران عادی

### اتصال ساده

- ساخت و ذخیره پروفایل اتصال
- وارد کردن دامنه MasterDNS/StormDNS و کلید رمزنگاری
- انتخاب روش رمزنگاری، شامل `XOR`، `ChaCha20` و حالت‌های مختلف `AES-GCM`
- روشن و خاموش کردن اتصال از صفحه اصلی
- نمایش وضعیت اتصال: آماده، در حال اتصال، متصل یا خطادار
- نمایش آدرس پراکسی محلی، مثل `127.0.0.1:10886`

### وارد کردن پروفایل آماده

- امکان Import کردن یک یا چند لینک پروفایل `stormdns://`
- ساخت خودکار پروفایل‌های اتصال از لینک‌های آماده
- انتخاب Resolver مناسب برای هر پروفایل اتصال
- جلوگیری از حذف پروفایل پیش‌فرض یا پروفایل فعال در زمان اتصال

### پراکسی محلی برای برنامه‌ها

- ارائه پراکسی محلی با Xray-core
- پشتیبانی از حالت Mixed برای استفاده هم‌زمان SOCKS و HTTP
- امکان انتخاب حالت SOCKS یا HTTP به‌صورت جداگانه
- امکان فعال کردن System Proxy برای تنظیم خودکار پراکسی سیستم
- امکان فعال کردن نام کاربری و رمز عبور برای پراکسی
- تنظیم IP و پورت پراکسی عمومی
- تنظیم Listener داخلی MasterDNS/StormDNS پشت Xray-core

### مدیریت Resolverها

- ساخت چند لیست Resolver جداگانه
- وارد کردن Resolverهای IPv4، IPv6 و همراه با پورت
- اعتبارسنجی خودکار لیست Resolverها قبل از ذخیره
- نمایش Resolverهای معتبر و ورودی‌های نامعتبر
- نمایش Resolverهای فعال، آماده‌باش و ردشده در زمان اتصال
- ذخیره Resolverهای سالم فعلی به عنوان یک پروفایل جدید

### پایش وضعیت اتصال

- نمایش سرعت دانلود و آپلود به‌صورت زنده
- نمایش مقدار کل مصرف داده
- نمایش تعداد Resolverهای معتبر
- نمایش روند راه‌اندازی اتصال با درصد پیشرفت
- نمایش هشدار کیفیت MTU وقتی تعداد Resolverها یا وضعیت شبکه مناسب نباشد
- امکان توقف و ادامه دادن اسکن MTU در زمان اتصال

### تنظیمات آماده و قابل تغییر

- ساخت چند پروفایل تنظیمات برای شرایط مختلف شبکه
- انتخاب حالت شروع اتصال: اسکن کامل، استفاده از لاگ‌ها یا پرسش از کاربر
- تنظیم سطح لاگ برای عیب‌یابی
- فعال یا غیرفعال کردن Base Encode Data
- فعال کردن DNS محلی و انتخاب پورت آن
- انتخاب روش بالانس بین Resolverها: تصادفی، Round Robin، کمترین Packet Loss یا کمترین Latency
- تنظیم تعداد تکرار بسته‌ها برای آپلود و دانلود جهت پایداری بیشتر
- انتخاب سطح فشرده‌سازی آپلود و دانلود
- تنظیم محدوده MTU برای آپلود و دانلود
- تنظیم تعداد تلاش، Timeout و میزان موازی‌سازی برای تست‌های MTU
- تنظیم منابع برنامه مثل Workerها، اندازه صف‌ها و تعداد Streamهای فعال
- تنظیم زمان‌های Timeout و Retry برای شبکه‌های ناپایدار
- تنظیم Watchdog برای بررسی زنده بودن اتصال

### اسکن و تست Endpointها

- تست سریع یک Host با یک یا چند پورت
- وارد کردن SNI اختیاری برای تست‌های TLS
- اسکن گروهی Endpointها از متن، فایل TXT، CSV یا JSON
- امکان لغو اسکن در حال اجرا
- امکان پاک کردن نتیجه‌های قبلی
- تنظیم تعداد تلاش مجدد، Timeout و تعداد تست هم‌زمان
- انتخاب مسیرهای HTTP برای تست
- فعال یا غیرفعال کردن تست‌های UDP، QUIC/H3، DNS و WebSocket
- امکان تست TLS ناامن برای محیط‌های خاص

### نتیجه‌های قابل فهم برای اسکن

- نمایش امتیاز و Grade برای هر Endpoint
- نمایش اینکه Endpoint برای Tunnel آماده است یا نه
- نمایش RTT، Jitter، Packet Loss و Stability
- نمایش وضعیت TCP، TLS، HTTP، WebSocket، UDP، QUIC و DNS
- نمایش بهترین امتیاز بین نتیجه‌ها
- امکان دیدن خروجی کامل JSON برای هر نتیجه
- امکان کپی کردن نتیجه خام برای بررسی دقیق‌تر

### لاگ و عیب‌یابی

- نمایش لاگ‌های اجرای برنامه
- جست‌وجو داخل لاگ‌ها
- نمایش پیام خطای قابل فهم در رابط کاربری
- نگهداری آخرین لاگ‌ها برای بررسی مشکل‌های اتصال

### خروجی گرفتن از تنظیمات

- خروجی گرفتن از تنظیمات اتصال فعلی به صورت `client_config.toml`
- خروجی گرفتن از هر پروفایل تنظیمات به صورت TOML
- امکان کپی سریع خروجی برای استفاده در محیط‌های دیگر

### نصب و بسته‌بندی

- نسخه نهایی می‌تواند MasterDNS/StormDNS client و Xray-core را داخل خود برنامه داشته باشد
- در حالت بسته‌بندی‌شده، کاربر معمولی نیازی به کنار گذاشتن فایل‌های جداگانه `clients` یا `cores` کنار برنامه ندارد
- پشتیبانی از ساخت بسته برای macOS، Windows و Linux
- انتشار بسته‌های Linux به شکل DEB، RPM و `tar.gz`
- پشتیبانی از macOS Universal و نسخه‌های Windows و Linux برای معماری‌های رایج

## راهنمای انتخاب نسخه ویندوز

برای ویندوز ۱۰ یا ۱۱ معمولی که در تنظیمات سیستم به شکل `64-bit` نمایش داده می‌شود، نسخه `Windows x64` را دانلود کنید. این نسخه برای پردازنده‌های Intel و AMD است و انتخاب درست برای بیشتر کامپیوترها و لپ‌تاپ‌های ویندوزی محسوب می‌شود.

نسخه `Windows ARM64` فقط برای دستگاه‌های Windows on ARM است؛ مثل دستگاه‌های Snapdragon یا Surface Pro X. اگر این نسخه را روی ویندوز معمولی Intel/AMD اجرا کنید، ویندوز خطای `This app can't run on your PC` نشان می‌دهد.

## راهنمای انتخاب نسخه macOS

برای مک‌های Apple Silicon مثل M1، M2، M3 و مدل‌های جدیدتر، نسخه `macos-arm64.zip` را از بخش Release دانلود کنید. برای مک‌های Intel، نسخه `macos-amd64.zip` را دانلود کنید.

فایل macOS باید به شکل ZIP آماده‌ی Release منتشر شود. اگر پوشه خام `.app` را از Artifacts گیت‌هاب دانلود یا دوباره فشرده کنید، ممکن است مجوز اجرای فایل داخلی برنامه از بین برود و macOS پیام `The application can't be opened` نشان دهد.

## مناسب برای چه کسانی است؟

- کاربرانی که می‌خواهند WhiteDNS را با رابط گرافیکی و بدون ترمینال اجرا کنند
- کاربرانی که چند سرور یا چند پروفایل دارند و می‌خواهند سریع بین آن‌ها جابه‌جا شوند
- کسانی که می‌خواهند قبل از استفاده، Endpointها و Resolverها را تست کنند
- کاربرانی که در شبکه‌های ناپایدار هستند و به تنظیمات پایداری، MTU و Retry نیاز دارند
- کاربران حرفه‌ای‌تر که می‌خواهند تنظیمات خروجی TOML بگیرند و آن را در جای دیگری استفاده کنند

## یادداشت ایمنی

Scanner فقط Endpointهایی را تست می‌کند که کاربر وارد یا Import کرده است. از این ابزار برای اسکن بی‌اجازه شبکه‌ها یا سرویس‌های دیگران استفاده نکنید. استفاده از برنامه باید مطابق قوانین محل زندگی و مسئولیت خود کاربر باشد.
