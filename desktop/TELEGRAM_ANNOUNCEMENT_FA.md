# متن پیشنهادی اعلام انتشار در تلگرام

WhiteDNS Desktop منتشر شد

نسخه دسکتاپ WhiteDNS حالا آماده استفاده است. این برنامه برای کسانی ساخته شده که می‌خواهند اتصال MasterDNS/StormDNS را روی کامپیوتر ساده‌تر، سریع‌تر و بدون درگیر شدن با ترمینال و فایل‌های تنظیمات اجرا کنند.

با WhiteDNS Desktop می‌توانید پروفایل اتصال را وارد کنید، Resolverها را مدیریت کنید، اتصال را با یک دکمه روشن یا خاموش کنید و وضعیت همه‌چیز را به‌صورت زنده ببینید.

امکانات اصلی:

- اتصال و قطع اتصال با یک دکمه
- رابط گرافیکی ساده برای Windows، macOS و Linux
- پراکسی محلی آماده برای مرورگرها و برنامه‌های دیگر
- پشتیبانی از SOCKS و HTTP از طریق Xray-core
- امکان فعال کردن System Proxy
- وارد کردن پروفایل‌های آماده با لینک `stormdns://`
- ساخت و مدیریت چند پروفایل اتصال
- ساخت و مدیریت چند لیست Resolver
- بررسی خودکار معتبر بودن Resolverها
- نمایش Resolverهای فعال، آماده‌باش و ردشده
- نمایش سرعت دانلود، سرعت آپلود و مصرف کل داده
- نمایش روند اتصال و درصد پیشرفت هنگام راه‌اندازی
- توقف و ادامه دادن تست MTU در زمان اتصال
- خروجی گرفتن از تنظیمات به شکل `client_config.toml`
- بخش لاگ و جست‌وجوی لاگ‌ها برای عیب‌یابی راحت‌تر

برای شبکه‌های ضعیف و ناپایدار هم تنظیمات پیشرفته در برنامه قرار داده شده است:

- انتخاب روش بالانس بین Resolverها
- تنظیم Packet Duplication برای پایداری بیشتر
- تنظیم فشرده‌سازی آپلود و دانلود
- تنظیم MTU، Timeout، Retry و میزان تست هم‌زمان
- کنترل Workerها، Streamها و صف‌ها برای سیستم‌های مختلف
- Watchdog برای بررسی زنده بودن اتصال

یک ابزار Scanner هم داخل برنامه اضافه شده است:

- تست سریع یک Host با چند پورت
- اسکن گروهی از فایل TXT، CSV یا JSON
- تست TCP، TLS، HTTP، WebSocket، UDP، QUIC/H3 و DNS
- نمایش امتیاز، Grade، Latency، Jitter، Packet Loss و Stability
- نمایش اینکه Endpoint برای Tunnel آماده هست یا نه
- امکان دیدن و کپی کردن نتیجه کامل JSON

این نسخه برای کاربران عادی طراحی شده، اما تنظیمات حرفه‌ای هم برای کسانی که می‌خواهند اتصال را دقیق‌تر با شرایط شبکه خود هماهنگ کنند در دسترس است.

راهنمای دانلود برای ویندوز:

اگر ویندوز شما ۶۴ بیتی معمولی است و پردازنده Intel یا AMD دارید، نسخه `Windows x64` را دانلود کنید. نسخه `Windows ARM64` مخصوص دستگاه‌های Windows on ARM مثل Snapdragon یا Surface Pro X است و روی بیشتر کامپیوترهای ۶۴ بیتی معمولی اجرا نمی‌شود.

راهنمای دانلود برای macOS:

برای مک‌های Apple Silicon مثل M1، M2، M3 و مدل‌های جدیدتر، نسخه `macos-arm64.zip` را از Release دانلود کنید. اگر برنامه پیام `The application can't be opened` نشان داد، معمولاً فایل به شکل درست ZIP نشده یا پوشه خام `.app` از Artifacts دانلود شده است؛ نسخه ZIP داخل Release را استفاده کنید.

راهنمای دانلود برای Linux:

برای بیشتر کاربران Linux روی Intel/AMD، ساده‌ترین انتخاب فایل `.AppImage` است، چون نیاز به نصب بسته DEB یا RPM برنامه ندارد.

برای Debian و Ubuntu می‌توانید فایل `.deb` را دانلود کنید. برای توزیع‌های RPM مثل Fedora یا Rocky، اگر سیستم شما WebKitGTK 4.1 دارد نسخه `linux-amd64-webkit41.rpm` را انتخاب کنید. فایل `tar.gz` هم به‌عنوان حالت عمومی وجود دارد، اما به GTK 3 و WebKitGTK مناسب از خود توزیع نیاز دارد.

نکته مهم:
Scanner فقط آدرس‌هایی را تست می‌کند که خود کاربر وارد یا Import کرده باشد. از این ابزار برای تست یا اسکن بی‌اجازه سرویس‌ها و شبکه‌های دیگران استفاده نکنید.

این نسخه بتا است. اگر مشکلی دیدید، گزارش خطا، لاگ و توضیح شرایط شبکه کمک زیادی به بهتر شدن نسخه‌های بعدی می‌کند.
