## تازه در ۱.۰.۲۴

- **فرگمنت اتصال، مشابه WhiteVPN موبایل ۱.۷.۱:** شش پیشنهاد آماده، JSON قابل ویرایش و تنظیمات ALPN و مجموعه رمزهای TLS.
- دسترسی از صفحهٔ VPN و تنظیمات؛ تغییر تنظیماتِ فعال، اتصال را دوباره برقرار می‌کند.
- تست تأخیر و سرعت از همان تنظیمات فرگمنت استفاده می‌کند.
- اگر اتصال برقرار نشود، برنامه ابتدا فرگمنت با تنظیمات TLS سرور و سپس اتصال عادی را امتحان می‌کند. حالت واقعی اتصال روی داشبورد نمایش داده می‌شود.
- اصلاح سازگاری `maxSplit` و حفظ پیشنهاد انتخاب‌شده بعد از خروج از تنظیمات.

فرگمنت به‌صورت پیش‌فرض خاموش است. این قابلیت برای اتصال‌های TCP است و روی WARP/WireGuard و Hysteria2 اعمال نمی‌شود. اثر آن به شبکه و سرور بستگی دارد؛ موفقیت در همهٔ شبکه‌ها تضمین نمی‌شود.

## What's new in 1.0.24

- **Connection fragments matching WhiteVPN Android 1.7.1:** six FinalMask presets, editable JSON, ALPN and TLS cipher-suite overrides.
- Open fragment settings from the VPN dashboard or Settings. Applying changed active settings reconnects the VPN.
- Latency and speed tests use the same fragment configuration as the connection.
- Startup retries with server TLS settings and then without fragments when needed. The dashboard reports the mode that actually connected.
- Includes the 1.7.1 `maxSplit` compatibility correction and retains the selected preset after navigation.

Fragments are off by default. They apply to TCP proxy connections; WARP/WireGuard and Hysteria2 retain their own transport behaviour. Effectiveness depends on the network and server.

This release also includes the Windows MSI installers, “All servers” selection and tray connection-mode controls previously available in 1.0.23-rc1. Existing subscriptions and settings are retained.
