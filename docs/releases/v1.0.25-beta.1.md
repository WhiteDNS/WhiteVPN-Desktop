## تازه در ۱.۰.۲۵ بتا ۱ — هم‌تراز با WhiteVPN موبایل ۱.۸.۰ بتا ۲

- **روش اتصال در یک نگاه:** در صفحهٔ VPN فقط یک سؤال هست: «چطور وصل شوید؟» با پنج گزینهٔ خودکار، دو سرور پشت هم، WARP، Psiphon و Tor. فقط تنظیماتی دیده می‌شود که به همان گزینه مربوط است.
- **WARP (Cloudflare):** ساخت حساب رایگان WARP با یک دکمه، ویرایش IP سرور، پورت و نویز ضدفیلتر. کلید خصوصی فقط در خزانهٔ رمزگذاری‌شدهٔ ویندوز می‌ماند.
- **Psiphon و Tor:** دو موتور اتصال تازه در بخش «موتورهای اتصال». Tor از بستهٔ رسمی Tor Expert Bundle با پل‌های obfs4، snowflake و conjure.
- **دو سرور پشت هم:** نود ۱ و نود ۲ از هر اشتراکی. برای هر فهرست می‌توانید کانفیگ‌ها را تست کنید و یکی را انتخاب کنید، یا «خودکار» را بگذارید تا سریع‌ترین کانفیگ همان فهرست انتخاب شود. کانفیگ‌های ناسازگار با دلیل نشان داده می‌شوند.
- **ECH خودکار:** برای اتصال‌های CDN (WebSocket، gRPC و XHTTP) نام سایت پنهان می‌شود؛ اگر سرور ECH نداشته باشد، با TLS معمولی وصل می‌شود.
- **هستهٔ تازه:** mihomo v1.19.34، همان هستهٔ نسخهٔ موبایل.
- اگر اتصال رد شود، دلیل واقعی نمایش داده می‌شود.
- دکمهٔ تلگرام کنار یوتیوب.

این نسخه پیش‌انتشار است و به‌روزرسانی خودکار آن را پیشنهاد نمی‌دهد. Tor فقط در نسخهٔ ویندوز x64 موجود است.

## What's new in 1.0.25-beta.1 — matching WhiteVPN Android 1.8.0-beta.2

- **One plain choice of how to connect:** the VPN page asks "How do you want to connect?" — Automatic, Double server, WARP, Psiphon or Tor — and shows only the settings that choice uses.
- **WARP (Cloudflare):** create a free WARP account in one click; edit its server IP, port and anti-filter noise. The private key stays in the Windows-encrypted vault.
- **Psiphon and Tor:** two new connection engines under Connection engines. Tor ships from the official Tor Expert Bundle with obfs4, snowflake and conjure bridges.
- **Double server:** node 1 and node 2 from any subscription. Per list, test the configs and pick one, or choose Automatic for the fastest working config in that list. Incompatible configs are shown with the reason.
- **Automatic ECH:** hides the site name of CDN connections (WebSocket, gRPC, XHTTP) when the server supports ECH, falling back to plain TLS when it does not.
- **New core:** mihomo v1.19.34, the same core as the phone app.
- A refused connection now shows the real reason.
- A Telegram button beside YouTube.

This is a pre-release; the in-app update check does not offer it. Tor is available in the Windows x64 build only.
